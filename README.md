# homebrew-tap

Homebrew tap for [rigortype](https://github.com/rigortype) tools.

## Install

```sh
brew install rigortype/tap/lisplens
```

The first `install` taps this repository automatically. Thereafter:

```sh
brew upgrade lisplens
```

tracks new releases.

## Formulae

- **lisplens** — token-efficient, polyglot Lisp editing for AI agents (CLI/MCP).
  Source: <https://github.com/rigortype/lisplens>

## Maintenance

`Formula/lisplens.rb` is generated and pushed automatically by the
[lisplens release workflow](https://github.com/rigortype/lisplens/blob/master/.github/workflows/release.yml)
on each `vX.Y.Z` tag — do not edit it by hand.
